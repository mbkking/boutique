## TEST CRITIQUE DE SUPPRESSION

Après suppression :

1. vérifier l'interface admin ;
2. actualiser la page ;
3. vérifier l'application client ;
4. vérifier directement Supabase ;
5. vérifier les relations avec les autres tables ;
6. vérifier les éventuels caches ;
7. vérifier les API ;
8. vérifier le comportement après reconnexion.

Un produit supprimé ne doit pas continuer à être présenté comme actif sans raison métier.

Si le système utilise une suppression logique/soft delete, ce n'est pas forcément un bug.

Dans ce cas, déterminer :

- quel champ indique la suppression ;
- pourquoi la donnée reste en DB ;
- si c'est volontaire ;
- si le frontend filtre correctement les éléments supprimés.

Ne conclus jamais automatiquement que "présent dans DB = bug".
